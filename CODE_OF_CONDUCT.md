# Code of conduct

Glut follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be kind and patient, assume good intent, criticise ideas rather than people, and keep the conversation about
the work. Harassment, insults, and personal or political attacks are not welcome in issues, pull requests or
anywhere else the project lives.

If someone's behaviour troubles you, write to the maintainer privately through a
[security advisory](https://github.com/axiomata-labs/glut/security/advisories/new) — it reaches only the maintainer — or by
the e-mail address on the project's website. Every report is read and kept confidential.
