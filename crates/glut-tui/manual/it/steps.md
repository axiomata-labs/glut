/steps — ogni passo che ha cambiato un file; ⏎ su uno mostra cosa ha cambiato, o riporta i file a prima di esso

Ripristinare i file si porta dietro le tue modifiche successive; la conversazione resta. Glut conserva uno snapshot prima di ogni passo che cambia qualcosa; anche com’erano i file subito prima viene conservato, così `glut undo` lo riporta indietro. ⎋⎋ riavvolge invece la conversazione.
