Guarda cosa conserva la memoria del progetto: i fatti che Glut ha annotato per le sessioni successive.

/memory — i fatti con le loro descrizioni; ⏎ ne mostra uno per intero
/memory open — l’indice (`MEMORY.md`) nel tuo editor

La memoria sta fuori dal repository: in `~/.glut/memory/<project>/`, oppure nella memoria di Claude Code dove Claude Code lavora nel repository. Glut la scrive con il suo strumento `memory`; leggerla qui non interroga alcun modello.
