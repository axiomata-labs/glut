Ein Pane schließen oder einen Hintergrund-Agenten beenden.

/close — schließt dieses Pane (nie das Haupt-Pane); arbeitet es noch, hält ein zweites /close es an und schließt es
/close <name> — beendet diesen Hintergrund-Agenten, sein Turn wird angehalten
/close <n> — schließt Pane n von dort, wo du bist, über Nummer, Name oder Rolle; du bleibst in deinem Pane
/close allein, wenn mehr als dieses Pane zu schließen ist — eine Liste davon, dieses Pane zuerst: ⏎ schließt das gewählte

Die Session bleibt für /resume erhalten. Ein Pane in einem Worktree fragt, wie der Worktree endet: behalten samt Branch, übernehmen (in den Branch mergen, auf dem du bist) oder verwerfen. ⌃X 0 schließt dieses Pane ebenfalls.
