Eine Nachricht an ein anderes Pane oder einen Hintergrund-Agenten schicken, dort genommen, als hättest du sie getippt.

/send — eine Liste, wem du schreiben kannst: die Panes und Agenten hier, dann die anderen Glut-Fenster; ⏎ setzt /send <who> in die Eingabe
/send <text> — an das einzige andere Pane
/send <n|name> <text> — an Pane n oder den Agenten dieses Namens (bei drei oder mehr nötig)
/send plan — gibt den Plan dieses Panes dem anderen Pane zum Bauen
/send <n|name> plan — gibt ihn diesem

Die Nachricht beginnt sofort, wo die Session ruht, sonst nach ihrem Turn. Die Tasten bleiben in diesem Pane.
