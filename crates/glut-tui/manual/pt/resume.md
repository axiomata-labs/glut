Abre uma sessão anterior desta pasta e continua nela.

/resume — a lista das sessões guardadas desta pasta, a mais recente primeiro; uma ramificação fica sob a sessão de onde veio

Na lista: digite para filtrar, ⏎ abre uma, ⌫ apaga uma (com confirmação; as ramificações dela continuam como sessões próprias), ⌃E escreve uma como Markdown em `~/.glut/exports`. Uma sessão aberta em outro pane se alcança lá (⌃P).

/search encontra uma sessão pelo que foi dito nela.
