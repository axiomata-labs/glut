Mostra o que a memória do projeto guarda: os fatos que o Glut anotou para as sessões seguintes.

/memory — os fatos com as descrições deles; ⏎ mostra um por inteiro
/memory open — o índice (`MEMORY.md`) no seu editor

A memória fica fora do repositório: em `~/.glut/memory/<project>/`, ou na memória do Claude Code onde o Claude Code trabalha no repositório. O Glut a escreve com a ferramenta `memory` dele; lê-la aqui não consulta nenhum modelo.
