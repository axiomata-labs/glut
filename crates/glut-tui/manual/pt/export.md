Escreve a sessão para ler ou compartilhar.

/export — Markdown em `~/.glut/exports`
/export html — um arquivo HTML, com os estilos dentro, sem script
/export jsonl — as mensagens como linhas JSON
/export copy — o Markdown na área de transferência, em vez de um arquivo
/export full — inclui os resultados inteiros das ferramentas e o prompt do sistema
/export <format> <path> — para um arquivo seu (`~/` é a sua pasta pessoal, um caminho relativo fica na pasta de trabalho)

As palavras vão em qualquer ordem, o caminho por último. Sem full, a exportação mostra o que o modelo viu: resultados longos encurtados. Um arquivo existente nunca é sobrescrito. As chaves que o Glut ocultou continuam ocultas, mas o que você mesmo digitou ainda pode conter uma: leia uma exportação antes de compartilhá-la. No /resume, ⌃E exporta uma sessão da lista.
