Uma regra para esta sessão que o modelo segue a cada turno.

/rule <text> — guardá-la, como «atualize a lista de tarefas a cada passo»
/rule — as regras atuais, numeradas
/rule remove <n> — retirar a regra n

As regras vão com as instruções de cada turno, depois dos guias, até você retirá-las; /clear as mantém, uma sessão nova começa sem elas. No máximo 20, de 500 caracteres cada. Para uma regra de toda sessão, escreva-a em `~/.glut/AGENTS.md` ou no guia do projeto.
