Escreve um `AGENTS.md` curto para esta pasta, ou verifica e encurta o guia que ela tem.

/init — sem guia o Glut escreve o `AGENTS.md`; com um, ele o verifica e o mantém curto
/init --migrate — pergunta de novo se o `CLAUDE.md` passa para o `AGENTS.md`

Com só um `CLAUDE.md`, o Glut pergunta uma vez se ele passa para o `AGENTS.md` (o `CLAUDE.md` então o importa, um guia para todo harness); um não é guardado. Os guias vão junto a cada turno: /context mostra o que custam.
