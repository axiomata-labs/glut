Fecha um pane, ou encerra um agente em segundo plano.

/close — fecha este pane (nunca o principal); enquanto ele trabalha, um segundo /close o para e o fecha
/close <name> — encerra esse agente em segundo plano, com o turno dele parado
/close <n> — fecha o pane n de onde está, pelo número, nome ou papel; fica no seu pane
/close sozinho, se houver mais do que este pane para fechar — uma lista, este pane primeiro: ⏎ fecha o escolhido

A sessão é guardada para o /resume. Um pane num Worktree pergunta como o Worktree termina: guardá-lo com a branch dele, incorporá-lo (fazer o merge dele na branch em que você está) ou descartá-lo. ⌃X 0 também fecha este pane.
