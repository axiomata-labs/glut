Una regla para esta sesión que el modelo sigue en cada turno.

/rule <text> — guardarla, como «actualiza la lista de tareas en cada paso»
/rule — las reglas actuales, numeradas
/rule remove <n> — retirar la regla n

Las reglas van con las instrucciones de cada turno, tras las guías, hasta que las retires; /clear las conserva, una sesión nueva empieza sin ellas. Como máximo 20, de 500 caracteres cada una. Para una regla de cada sesión, escríbela en `~/.glut/AGENTS.md` o en la guía del proyecto.
