Voir ce que garde la mémoire du projet : les faits que Glut a notés pour les sessions suivantes.

/memory — les faits avec leurs descriptions ; ⏎ en montre un en entier
/memory open — l’index (`MEMORY.md`) dans ton éditeur

La mémoire se trouve hors du dépôt : dans `~/.glut/memory/<project>/`, ou dans la mémoire de Claude Code là où Claude Code travaille dans le dépôt. Glut l’écrit avec son outil `memory` ; la lire ici ne sollicite aucun modèle.
