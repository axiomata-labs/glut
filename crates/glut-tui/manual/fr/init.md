Écrire un court `AGENTS.md` pour ce dossier, ou vérifier et raccourcir le guide qu’il a.

/init — sans guide, Glut écrit `AGENTS.md` ; avec un guide, il le vérifie et le garde court
/init --migrate — redemande si `CLAUDE.md` passe dans `AGENTS.md`

Avec un `CLAUDE.md` seul, Glut demande une fois s’il passe dans `AGENTS.md` (`CLAUDE.md` l’importe alors, un seul guide pour tous les harness) ; un non est retenu. Les guides accompagnent chaque tour : /context montre ce qu’ils coûtent.
