Choisir le modèle avec lequel cette session parle.

/model — les modèles du fournisseur utilisé, d’après sa liste gardée
/model <id> — passe à ce modèle par son id

La conversation continue avec le nouveau modèle, et le prochain démarrage commence avec lui. Un modèle d’un autre fournisseur se choisit après /provider. `glut models refresh` renouvelle les listes.
