Envoyer un message à un autre pane ou à un agent en arrière-plan, reçu là-bas comme si tu l’avais tapé.

/send — une liste de destinataires : les panes et agents d'ici, puis les autres fenêtres Glut ; ⏎ met /send <who> dans la saisie
/send <text> — au seul autre pane
/send <n|name> <text> — au pane n ou à l’agent de ce nom (nécessaire à partir de trois panes)
/send plan — passe le plan de ce pane à l’autre pane pour le construire
/send <n|name> plan — le passe à celui-là

Le message démarre aussitôt là où la session se repose, sinon après son tour. Les touches restent dans ce pane.
