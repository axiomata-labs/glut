Chaque commande et chaque touche, dans une boîte à part.

/help — les commandes avec une ligne chacune ; taper les filtre, ↑↓ choisissent, ⏎ ouvre la page entière de l’une d’elles
/help <command> — la page de cette commande aussitôt, comme /help loop

Sur une page, ↑↓ et PgUp PgDn font défiler, ⎋ revient à la liste et ferme la boîte depuis là. La dernière entrée contient chaque touche par sujet, !cmd et le mode vi ; ⌃K garde les touches dans le panneau latéral.
