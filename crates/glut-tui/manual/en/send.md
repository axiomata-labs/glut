Send a message to another pane or background agent, taken there as if you had typed it.

/send — a list of whom to write to: the panes and agents here, then the other Glut windows; ⏎ puts /send <who> into the input
/send <text> — to the only other pane
/send <n|name> <text> — to pane n or the agent of that name (needed with three or more)
/send plan — hands this pane's plan to the other pane to build
/send <n|name> plan — hands it to that one

The message starts at once where the session rests, otherwise after its turn. The keys stay in this pane.
