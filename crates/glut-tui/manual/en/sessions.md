Write to the other Glut windows on this machine.

/sessions — their panes and agents: address, project, model, mode, working or waiting; ⏎ puts /send <address> into the input
/sessions off — this window takes no messages from them
/sessions on — and again

A message from the owner there goes in at once; one from a model there only when it runs in the mode of the pane it reaches, else it waits above the input: ⏎ lets it in, Esc drops it. Neither is your word to the model here. Only Glut talks to the other windows — a command of the model's never reaches them.
