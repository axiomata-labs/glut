Start an agent in the background: a session with no pane, reached by its name.

/bg — an agent named agent (or agent-2, …); in a git repository Glut asks where it works
/bg <name> — an agent of that name (small letters, digits and dashes)
/bg as <role> — it plays a role, and is named after it
/bg here — it works in this folder
/bg tree [branch] — it works in a new Worktree

/send <name> gives it work, /peek <name> reads its stream, /show <name> brings it forward, /close <name> ends it. Each agent works and costs on its own: Glut asks once a window before a seventh. ⌃X B starts one with its role picked, ⌃X A lists them.
