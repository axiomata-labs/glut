このセッションに作業フォルダーの横のフォルダーを加え、Glut がプロジェクトをまたいで作業できるようにします。

/folder — 作業フォルダーの横にあるフォルダー
/folder add <path> — このセッションに一つ追加します
/folder remove <path> — 一つ外します

ファイルツールはそのフォルダーにフルパスで届き、コマンドはサンドボックスの内側でそこに書き込めます。Gate は作業フォルダーと同じように判定し、undo もそこのファイルを元に戻します。フォルダーを加えられるのはあなただけです。モデル、Skill、プロジェクトは加えられません。Glut が拒否するのは、ホームフォルダー、プロジェクトを含むフォルダーやその内側のフォルダー、秘密を含むフォルダー、互いに入れ子になった二つのフォルダーです。

フォルダーはこのセッションの間だけ有効です。ヘッドレス実行には `glut run --folder <path>` で渡せます。
