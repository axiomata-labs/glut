MCP サーバーとそれぞれの状態を見て、ホスト型にサインインし、サーバーを追加・削除します。

/mcp — すべてのサーバー: ツール付きで接続済み、サインイン待ち、または失敗
/mcp login <name> — ホスト型サーバーにサインインします; そのアドレスは ⏎ でブラウザーに開きます
/mcp login <name> <address> — SSH 越しの場合: ブラウザーが最後に表示したアドレスを貼り戻します
/mcp logout <name> — サインアウトして、その Token を忘れます
/mcp add <name> <url> — ホスト型サーバーを `~/.glut/mcp.json` に追加して接続します
/mcp add <name> -- <command> [args] — Glut 自身が起動するサーバーを追加します
/mcp remove <name> — `~/.glut/mcp.json` とセッションから外します

Glut が使えるサインインを提供しないサーバーでは、Token を（非表示で入力して）尋ねます。プロジェクト自身のサーバーを変えられるのはプロジェクトだけです: /mcp remove が外せるのはあなたのものだけです。セッションの外では `glut mcp` が同じことをします。

ツールの実行中、サーバーがあなたに尋ねることがあります：フォーム（⇥ ↑↓ で項目を移動、スペースでチェック、⏎ で送信、Esc で閉じる、⌃D で拒否）または開くページ（o）。答えるのはあなただけで、モデルではありません。パスワードやキーを求めるフォームは拒否され、誰もいないときはすべての質問が拒否されます。
