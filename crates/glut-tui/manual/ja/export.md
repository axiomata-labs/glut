セッションを読んだり共有したりするために書き出します。

/export — Markdown を `~/.glut/exports` へ
/export html — スタイルを内蔵した、スクリプトなしの HTML ファイル 1 つ
/export jsonl — メッセージを JSON 行で
/export copy — ファイルではなく Markdown をクリップボードへ
/export full — ツール結果の全文とシステムプロンプトも加えます
/export <format> <path> — 自分で決めたファイルへ（`~/` はホームフォルダー、相対パスは作業フォルダー内）

語は順不同で、パスは最後に置きます。full なしの書き出しは、モデルが見たとおりのもの（長い結果は短縮）です。既存のファイルは上書きされません。Glut が隠したキーは隠れたままですが、自分で入力したものにはキーが含まれているかもしれません: 共有する前に書き出しを読んでください。/resume では ⌃E で一覧のセッションを書き出せます。
