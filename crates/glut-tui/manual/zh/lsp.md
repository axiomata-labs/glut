语言服务器是否帮助模型。

/lsp on — 编辑之后，文件的错误随结果一起返回，模型可以使用 lsp 工具：符号在哪里定义、在哪些地方使用、它的类型和文档，以及在整个项目中重命名
/lsp off — 不运行任何服务器：它们的进程立即结束，编辑后不再报错，也没有 lsp 工具
/lsp — 当前的选择，以及本会话的每个服务器：就绪、正在为项目建立索引，或本会话中已关闭

Glut 只启动从不运行项目代码的服务器（不带构建脚本和过程宏的 rust-analyzer、pyright，以及 TOML、YAML、JSON、CSS、HTML 和 Markdown 的服务器），只在没有网络的沙盒中，并且只在 Gate 允许其命令行时启动。服务器在其语言的第一次编辑或提问时启动，并在会话期间一直保留；rust-analyzer 为大型项目建立索引需要几秒钟，在此期间 lsp 会说明，模型改用 grep。重命名是一次更改：对所有文件只询问一次，要么全部要么都不，之前先拍快照。保存在 `~/.glut/prefs.json`；`~/.glut/settings.json` 中的 `"lsp": false` 对所有运行关闭，`glut run --no-lsp` 只对一次运行关闭。
