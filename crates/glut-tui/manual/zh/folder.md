给本会话添加工作文件夹旁的文件夹，使 Glut 能跨项目工作。

/folder — 工作文件夹旁的文件夹
/folder add <path> — 为本会话添加一个
/folder remove <path> — 移除一个

文件工具通过完整路径访问这样的文件夹，命令可在沙箱内写入其中，Gate 像对待工作文件夹一样判定它，撤销也会恢复其中的文件。只有你能添加文件夹，模型、Skill 或项目都不能。Glut 拒绝主目录、包含该项目或位于其内部的文件夹、含有密钥的文件夹，以及互相嵌套的两个文件夹。

这些文件夹只对本会话有效；`glut run --folder <path>` 可把一个文件夹交给无界面运行。
